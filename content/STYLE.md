# دليل أسلوب المحتوى — SmartTech

هذا المرجع مُلزِم لكل نص في المتجر. سببه أن الكتالوج تُرجم على عدة دفعات بلا
قاموس موحّد، فاختلف ترتيب الأسماء بين العائلة الواحدة، وتعدّدت تسميات المفهوم
الواحد، وبقيت وحدات إنكليزية عند بعض المنتجات دون غيرها.

---

## 1. ترتيب اسم المنتج (عربي)

**القاعدة: الاسم العربي للنوع أولاً، ثم اسم الخط أو الموديل باللاتينية، ثم الأقواس.**

| ✅ صحيح | ❌ خطأ |
|---|---|
| `شاحن Prime (200W، 6 منافذ، GaN)` | `Prime شاحن (200W، 6 منافذ، GaN)` |
| `بطارية متنقلة MagGo (6.6K)` | `MagGo بطارية متنقلة (6.6K)` |
| `شاحن Nano (45W)` | `Nano شاحن (45W)` |
| `مقبض PITAKA Grip3 (Moonrise)` | `PITAKA مقبض Grip3 (Moonrise)` |
| `كاميرا Bullet-PTZ S4 بتقنية PoE` | `كاميرا Bullet-PTZ بتقنية PoE S4` |

رمز الموديل يبقى ملتصقاً بما يصفه، لا يُفصل عنه.
الأسماء التي تبدأ برقم موديل فقط (`S230`، `E30`، `A400`) تأخذ اسم النوع قبلها:
`كاميرا SoloCam S40 بدقة 2K` لا `S230 SoloCam 2K (S40)`.

## 2. ما يبقى باللاتينية دائماً

العلامات والموديلات والألوان التجارية والوحدات:
`Anker`، `eufy`، `PITAKA`، `MagSafe`، `Qi2`، `USB-C`، `PowerIQ`،
`Sunset`، `Moonrise`، `California Dream-01`، `600D Black/Grey-Twill`،
`100W`، `20000mAh`، `4K`، `IP67`، `MIL-STD-810H`.

**لا تُترجم أسماء الألوان التجارية ولا تُنقل حرفياً.** `600D Black/Grey-Twill`
تبقى كما هي — هي رمز يطابقه الزبون مع الصورة، وليست وصفاً.

## 3. الأرقام والوحدات

- أرقام غربية دائماً: `20000` لا `٢٠٠٠٠`.
- **بلا فاصل آلاف** في العربية والإنجليزية: `20000mAh`، `10000` طيّة، `15000 Pa`.
- الوحدة ملتصقة بالرقم بلا مسافة: `100W`، `20000mAh`، `46 dB` (استثناء: `dB` و`Pa` بمسافة).
- التركية وحدها تستعمل `.` للآلاف و`,` للكسور: `20.000mAh`، `22,5W`.
- الكسور العشرية بنقطة في العربية والإنجليزية: `22.5W`.

### تحويل الوحدات الإمبراطورية — إلزامي

لا يُترك رطل ولا قدم ولا أونصة ولا فهرنهايت في نص عربي أو تركي.
اكتب المتري وحده، لا المتري بين قوسين بعد الإمبراطوري.

| المصدر | العربية | التركية |
|---|---|---|
| `30 ft` | `9 أمتار` | `9 metre` |
| `164 ft` | `50 متراً` | `50 metre` |
| `220 lbs` | `100 كغ` | `100 kg` |
| `7.65 oz` | `217 غ` | `217 g` |
| `0.35 inch` | `9 مم` | `9 mm` |
| `104°F` | `40°م` | `40°C` |
| `61 qt` | تُحذف (اللترات كافية) | تُحذف |

الإنشات تبقى فقط لقياس الشاشات: `شاشة 6.5 إنش`.

## 4. المصطلحات الموحّدة

| المعنى | استعمل | لا تستعمل |
|---|---|---|
| cable | `كابل` | كبل، وصلة، سلك |
| bend | `طيّة` | عملية ثني، ثنية، مرة ثني |
| braided | `مضفّر` | مضفور |
| ANC | `إلغاء الضجيج` | عزل الضجيج، خفض الضجيج |
| siren | `صفّارة` | صافرة، صفارة |
| decibel | `dB` | ديسيبل |
| speaker | `مكبّر صوت` | مكبر |
| robot vacuum | `مكنسة روبوت` | مكنسة روبوتية |
| mop | `ممسحة` | ماسحة |
| driver | `مشغّل صوتي` | وحدة صوتية |
| power bank | `بطارية متنقلة` | باور بانك (في أسماء المنتجات) |
| case | `غطاء` | كفر (في أسماء المنتجات) |
| switch (شبكة) | `مبدّل شبكة (Switch)` | سويتش |
| woofer | `وحدة جهير (ووفر)` | ووفر |
| slim | `نحيف` أو `انسيابي` | نحيل |

الوحدات المترية بالعربية: `مم`، `سم`، `م`، `كغ`، `غ` — لا `mm`, `cm`, `kg`, `g`.

## 5. التركية

- لواحق سليمة مع تناغم الحركات: `Anker'in` (لا `Anker'ın`)، `HDMI'ye`،
  `Gbps'ye`، `kWh'e`، `Max'ı`، `Max'ta`.
- علامة الاقتباس `"…"` في كل مكان، لا `«…»`.
- فاصلة عليا مستقيمة `'` لا `’`.
- `Powerbank` تسمية القسم، و`taşınabilir şarj cihazı` في النص.

## 6. الإنجليزية

- إملاء أمريكي في كل مكان: `fiber`, `color`, `meters`, `customize`, `optimize`, `centered`.
- بلا فاصل آلاف: `5000mAh`.
- أرقام لا كلمات: `10 sensors` لا `Ten sensors`.

## 7. ما لا يُكتب أبداً

- ادّعاء تفضيل على منافس («أفضل من علامات أخرى»).
- وعد خدمة يخص متجراً آخر («خدمة عملائنا الودودة»، «دعم 24/7»).
- تفوّق عالمي داخل اسم المنتج («أصغر جهاز عرض في العالم»).
- رقم أو شهادة أو توافق غير موجود في نص المورّد.
- مدة ضمان يلتزم بها المتجر — مدد المصنّع تُذكر داخل «محتويات العلبة» فقط.
